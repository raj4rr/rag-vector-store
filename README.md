# RAG Vector Store with Spring AI, Ollama & Redis

A Spring Boot 3 & Spring AI application demonstrating **Retrieval-Augmented Generation (RAG)** using **Ollama** (local LLM & embeddings) and **Redis Stack** as the Vector Store. 

It features an interactive Web UI, chat memory retention using advisors, document ingestion pipelines (Markdown, PDF, Tika), and raw embedding inspection APIs.

---

## 🚀 Architecture & Technical Overview

```
 ┌─────────────────┐       ┌──────────────────────┐       ┌────────────────┐
 │                 │       │                      │       │                │
 │  Web Interface  │ ───>  │  Spring Boot App     │ ───>  │  Redis Vector  │
 │  (Bootstrap 5)  │  HTTP │  (ChatController)    │  RAG  │     Store      │
 │                 │ <───  │                      │ <───  │                │
 └─────────────────┘       └──────────┬───────────┘       └────────────────┘
                                      │
                                      │ Ollama API
                                      ▼
                           ┌──────────────────────┐
                           │    Ollama Engine     │
                           │ (qwen2.5 / nomic)    │
                           └──────────────────────┘
```

- **Framework**: Spring Boot 3.x with Spring AI
- **LLM Provider**: Ollama (`qwen2.5:0.5B-F16` model)
- **Embedding Provider**: Ollama (`nomic-embed-text:v1.5` embeddings)
- **Vector Store**: Redis Stack (`redis/redis-stack:7.2.0-v18`)
- **Document Ingestion**: Spring AI Document Readers (`MarkdownDocumentReader`, `PagePdfDocumentReader`, `TikaDocumentReader`) and `TokenTextSplitter`
- **Conversation State**: `MessageChatMemoryAdvisor` tracked via `X-CONV-ID` HTTP session cookies

## ⚙️ Configuration

Set properties in [`src/main/resources/application.properties`](file:///Users/rajesh/Desktop/Java/rag-vector-store/src/main/resources/application.properties):

```properties
spring.application.name=rag-ai-course
spring.ai.ollama.base-url=http://localhost:12434
spring.ai.ollama.chat.options.model=qwen2.5:0.5B-F16
spring.ai.ollama.chat.options.temperature=1
spring.ai.ollama.embedding.model=nomic-embed-text:v1.5

spring.ai.vectorstore.redis.initialize-schema=true
server.port=8080
```

## 🏃 Getting Started

### 1. Start Infrastructure (Redis Stack)

Run Docker Compose to spin up Redis Stack with vector search capabilities:

```bash
docker compose up -d
```

### 2. Build and Run the Application

Using Maven Wrapper or installed Maven:

```bash
mvn clean spring-boot:run
```

Upon startup, `AiConfig` automatically reads markdown files from `classpath:/data/` and ingests them into the Redis Vector Store.

### 3. Access Web Interface

Open your browser and navigate to:
```
http://localhost:8080
```

## 🔌 API Endpoints

### 1. RAG Chat Endpoint
- **URL**: `POST /api/chat`
- **Headers**: `Content-Type: application/json`
- **Body**:
  ```json
  {
    "prompt": "What are the key career lessons mentioned in the documents?"
  }
  ```
- **Response**: Returns HTML-rendered answer generated by Ollama using context retrieved from Redis vector store. Set-Cookie header manages `X-CONV-ID` for conversation history.

### 2. Similarity Vector Search
- **URL**: `GET /api/search?query=software+development`
- **Response**: Direct similarity search results against documents stored in Redis.

### 3. Raw Embedding Inspection
- **URL**: `GET /api/embedding?message=Hello+World`
- **Response**: Generates and returns raw floating-point vector embeddings using `EmbeddingModel`.
